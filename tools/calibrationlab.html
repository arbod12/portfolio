CalibrationLab does the model deserve trust?

An evaluation harness for an extraction model. Scores field-level accuracy against a labelled set, then tests whether the model's stated confidence means anything — if it says 90%, is it right 90% of the time? Ends with a threshold recommendation: the auto-approve cutoff that hits your tolerated error rate, and what it costs in review workload.

Evaluation run

One row per predicted field: field,confidence,correct — confidence 0-100, correct 1 or 0.

Policy

What the business can tolerate.
◍ Why this exists

A model's own confidence is untrusted input like any other output. This harness is the control that tests it: bin every prediction by stated confidence, compare against how often those predictions were actually right, and measure the gap. A model that is overconfident is dangerous precisely because it looks safe.
